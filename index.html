App Inventor Block Core

WebViewString IPC Pipe

Bi-directional inter-process string protocol. App Inventor pushes pipe-delimited data packets (bmi|status|range|prime|h|w|gauge) into the web DOM every tick.

1. Executive Summary & Core Purpose

CalcuFit is a standalone, client-side Android application designed for high-precision daily Body Mass Index (BMI) assessment, demographic tracking (Gender, Age), and healthy weight management. The system pairs the visual sophistication of modern web dashboards with the zero-dependency simplicity of MIT App Inventor 2.

Product Problem Statement

Standard App Inventor components lack native support for CSS corner radiuses, dynamic multi-color SVG circular arc meters, interactive button-group pills, and smooth severity transitions without brittle external extensions (.aix).

Engineered Architectural Solution

Decoupled architecture: MIT App Inventor operates as the pure backend controller (executing formulas, managing memory, and triggering modal dialogs), while a sandboxed Chromium WebViewer renders the vector presentation layer via local file loading.

3. Functional Requirements & Clinical Formulas

Quetelet BMI Calculation Formula FR-01
BMI = Weight_kg / (Height_m)²

Height is input in centimeters ($H_{\text{cm}}$), converted to meters ($H_{\text{m}} = H_{\text{cm}} / 100$), and evaluated to 1 decimal place using App Inventor’s format as number(x, 1) block.

Healthy Weight Range Bounds FR-02
W_min = 18.5 × (Height_m)²
W_max = 24.9 × (Height_m)²

Dynamically computes ideal clinical bounds based solely on the user's specific stature, rendered as a unified string: "{W_min} – {W_max} kg".

Gender & Age Demographics Capture FR-03

Provides dedicated pill controls for gender toggling (Male/Female) and interactive stepper logic for age adjustment (range: 5 to 100 years), updating the persistent Profile summary row: "{Gender}, {Age} yrs".

Dynamic Severity Color-Theming Engine FR-04

The visual theme dispatches dynamic hex color sets to SVG gradient stops (gradStop1, gradStop2), the BMI status badge, and the Prime Status tag based on the classification severity.

Vector Gauge Circumference & Stroke Dash Offset Equation FR-05
Circumference = 2 × π × 90 ≈ 565.487 px
StrokeOffset = Circumference - (GaugePercent / 100) × Circumference

The SVG circle uses stroke-dasharray="565.48". Smooth CSS hardware-accelerated transitions dynamically interpolate stroke-dashoffset across status updates.

5. Non-Functional & Operational Requirements

Zero-Network Autonomy (NFR-01)

App strictly operates without Wi-Fi or Cellular data. No remote analytic SDKs or telemetry beacons are injected, guaranteeing 100% HIPAA/GDPR health data privacy on-device.

Sub-100ms Input-to-Render Latency (NFR-02)

Poll frequency of 150ms ensures that any user calculation dispatched from native App Inventor blocks renders on the DOM with an imperceptible perceptual delay (< 85ms).

Adaptive Mobile Viewports (NFR-03)

Supports fluid aspect ratios spanning 16:9 to 21:9 across standard 320px compact devices up to large 11-inch Android tablets with dynamic font scaling.

Persistent Memory State (NFR-04)

TinyDB cache holds the most recently evaluated parameters under tag "lastCalculation", preventing cold-start data loss across restarts.
